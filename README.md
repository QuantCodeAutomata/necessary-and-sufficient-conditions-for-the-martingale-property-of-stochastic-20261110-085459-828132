# Necessary and Sufficient Conditions for the Martingale Property of Stochastic Exponentials Driven by Multi-Dimensional Diffusions

Replication of selected numerical experiments from Bayraktar, E. and Xing, H.,
*"Necessary and Sufficient Conditions for the Martingale Property of
Stochastic Exponentials Driven by Multi-Dimensional Diffusions."*

Every experiment is a Monte Carlo verification of an analytic martingale
criterion derived in the paper from the Fichera-drift / boundary-behaviour
analysis of a diffusion on a domain D. No external market data is used: all
inputs are the model coefficients specified in the paper's examples and
theorems (Sections 2, 3, 5, 6 and Appendix B).

## Layout

- `src/` — shared simulation primitives (`mc_core.py`), analytic criteria
  (`criteria.py`), model-specific Euler-Maruyama simulators (one file per
  model family), the PDE solver used in exp_11, and `config.py` with every
  parameter (grouped by experiment, each with a one-line source note).
- `exp/` — one script per experiment, run as `python -m exp.expN [--full]`.
- `tests/` — unit tests for `src/` and smoke tests for each experiment.
- `results/` — CSV tables, PNG figures and `RESULTS.md` with the comparison
  against the paper.
- `data/` — empty package: the experiments require no market or synthetic
  input data; every quantity is generated by simulating the diffusions the
  paper specifies.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Running

```bash
python -m pytest                       # full test suite
python -m exp.exp1                     # ... through exp.exp11, default (time-limited) configuration
python -m exp.exp1 --full              # paper-scale Monte Carlo sample sizes and time steps
```

`reproduce.sh` runs the test suite and every experiment in its default
configuration.

See `results/RESULTS.md` for the comparison of every experiment's output
against the paper's reported qualitative and quantitative results, together
with the "Deviations from the paper" and "Not reproduced" sections.
